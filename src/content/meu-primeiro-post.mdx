# Bem-vindo ao Meu Novo Blog!

Olá mundo! Este é o meu primeiro post utilizando **MDX** e o **Next.js App Router**. Decidi criar este espaço para compartilhar meus aprendizados sobre programação, design e tecnologia.

## Por que escolhi MDX?

O MDX é incrível porque me permite:
- Escrever textos usando a simplicidade do **Markdown**.
- Inserir blocos de código com facilidade.
- Renderizar componentes **React** interativos no meio do texto quando necessário.

Se você gostou da velocidade do site, saiba que ele é totalmente estático e otimizado para SEO!
